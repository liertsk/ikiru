# ikiru

Projeto acadêmico de desenvolvimento de um jogo de sobrevivência com perspectiva top-down, desenvolvido como atividade da disciplina.

## Sobre o projeto

O projeto está em fase inicial de desenvolvimento. A proposta conceitual, as mecânicas e a direção artística serão definidas ao longo da etapa de planejamento e da leitura da obra de referência.

## Tecnologias

- **Engine:** Godot
- **Linguagem:** GDScript
- **Versionamento:** Git e GitHub

## Estrutura do projeto

```text
projeto/
├── addons/       # Extensões e plugins
├── assets/       # Recursos visuais, sonoros e fontes
├── docs/         # Documentação do projeto
├── resources/    # Recursos e configurações reutilizáveis
├── scenes/       # Cenas do jogo
└── scripts/      # Scripts e lógica do jogo
```
- Pastas e arquivos com nomes em snake_case. 
- Classes GDScript com nomes em PascalCase.
- Scripts com extensão .gd.
- Cenas com extensão .tscn.
- Recursos da Godot com extensão correspondente (.tres, .res etc.).
- Evitar nomes genéricos como script1.gd, new_scene.tscn e test2.tscn.

## Desenvolvimento

O desenvolvimento é organizado por meio de GitHub Issues e GitHub Projects.

- `main`: versão estável do projeto.
- `dev`: branch de desenvolvimento.

## Execução

Abra o arquivo `project.godot` utilizando o Godot.
